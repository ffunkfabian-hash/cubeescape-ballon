   (Strahltest: dort liegt kein Bauteil).

   Cyan 0,7 statt 1,2 (AgX bleichte Cyan zu Hellblau). Budget 2 Leuchten, 1 Grafik, 1 Schrift, 0 Orange – eingehalten.
